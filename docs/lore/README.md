## 狀態標記

- 沒有標記的內容是已經決定的設定。
- 「草案」是方向已有、細節未定的內容。
- 「留白」是刻意先不決定的內容，寫作與設計時不要自行補上。
- 「待定」是設定集裡有幾種說法、還沒選定的內容，各說法並列。
- 「傾向，未定案」是作者已有初步傾向、但還不算定案的內容。

## 範圍

- 這裡只寫神權之戰這個時代，以及理解它所需的背景。
- 戰後的世界（七環大陸上的各國、新神的融合與分裂、各國信仰）不在範圍內。後世的故事可以把神權之戰當成模糊的傳說或神話，只要沒有根本性的矛盾即可。
- 種族與歷史只收到神權之戰結束、七環大陸成形為止。建國以後的各國度、現代的科技與城市都不收。
