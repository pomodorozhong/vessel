# 世界背景

神權之戰以前發生的事。這一頁只寫理解神權之戰所需的部分。

## 世界

- **雅拉**（Ira，意為蒼穹）是聖繭毀滅後留下的新世界，最初稱為努亞迪雅（新大陸）。
- **聖繭**是創世者撒冽亞在渾沌之海中創造的光之空間，已經毀滅。
- **亞空間**是與雅拉相鄰的空間層。亞空間之間可以互通，雖然困難，仍比回到雅拉容易。神的國度位於亞空間。
- 神權之戰開始時，大陸還是一整塊。分裂從菲亞海頓滅亡時開始，到神權之戰結束時完成，形成環繞伊利西亞洋的七環大陸。

## 先行的種族

- **永庭族**（The Arch）：最早的生命，研究生命本質，創造了萬物與智慧種族。他們為神權之戰定下規則，戰爭結束後自世間退隱。
- **龍族**：永庭族在聖繭時期創造的種族，隱居泰烽神域，世界滅亡之前不插手。
- **門戍族**：永庭族的遺民，守護鎮神劍與永庭族的遺物。只有門戍族有永庭信仰。
- **狂戰族**：異械戰爭中的遺骸與異械遺留的深淵石結合的產物，是世界之敵。

## 神權之戰以前的時間順序

1. **聖歌時代**：世界充滿聖歌。精靈的前身伊阿薩族建立菲亞海頓帝國，因聖歌而繁榮。
2. **狂戰族之戰**：狂戰族入侵，菲亞海頓帝國淪陷。為了封印狂戰族而重啟鎮神劍，聖歌幾乎在這時耗盡，帝國沉沒。
3. **泣霜露冬**：聖歌耗盡引發全球寒冰期，地勢劇變。
4. **萬族遷徙**：各族離開故地尋找落腳點。信仰在遷徙途中開始出現，有的族群有了信仰時還沒有地盤。
5. **定居與衝突**：各族定居之後，以神為中心的部落衝突白熱化，神權之戰開始。

## 時代的樣貌

- 文明是高科技與魔法的混合體。
- 經過帝國滅亡與長途遷徙，各族普遍尚武，許多建築與觀念是為戰爭服務的。
- 世界上仍然有大量沒有力量的普通人。
