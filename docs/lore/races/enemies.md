# 世界之敵

異械、狂戰族與盲魂。前兩者的來歷見 [../world-background.md](../world-background.md)，這裡補充條目細節。

## 異械（Hersis）

- 與永庭族交戰、導致聖繭毀滅的機械蟲族，認定生命的意義只有毀滅。別稱「外星生物」，是否保留待定。
- 外觀：融合機械與有機生命的特徵，由高強度金屬與仿生材料構成，充滿幾何感。有飛行型、爬行型、巨型破壞型等多種形態。
- 起源有三種說法（待定）：
  - 流星墜入聖繭而生。
  - 永庭族為探究生命意義而創造，得出「生命的意義只有毀滅」後吸收深淵能量並背叛。
  - 由被送入深淵的永庭族衛哨變成。
- 行為：如蟲族般分工，有工兵、戰士、指揮官。適應力與自我修復能力驚人，能迅速繁殖並吞噬資源。目標是消滅聖繭中央的始源光芒伊格尼斯。
- 主宰：蟲神鄒、卯、庫，三頭一體，形似蠕蟲又如巨蛇，巨大到精靈的身高只及其瞳孔。以精神網絡控制所有個體。「鄒」指三神之一或整體，待定。
- 戰爭分兩次（傾向，未定案）：聖繭時期是正式的異械戰爭；滅絕時期是封印復甦。
- 結局：異械徹底毀滅（傾向，未定案），與聖繭一同毀滅，遺骸化為深淵石。蟲神沒有死，被鎮神劍打入地底，永庭族在其上建睡夢之城鎮壓（傾向，未定案）。狂戰族之戰末期蟲神一度現身，再次被鎮神劍擊倒。
- 設計參考：《星海爭霸》的蟲族、人工智慧叛變。

## 狂戰族（Zealot）

- 異械戰爭的殘留物，由屍骸與深淵石結合而生的戰爭種族，被視為世界之敵。
- 外觀：以岩石紋路與骨骸為衣，頭長詭異的蔓生物。艦船稜角分明，黝黑帶紅紋，形如金字塔。
- 特性：保留少部分異械的蟲族特徵，但戰鬥方式更接近類人的智慧生物。不懼死亡，進攻不計代價，內部以強者為尊。擁有巡洋艦、無畏艦與蝗禍病毒，能污染有魔核的精靈。
- 權力核心：蜂璽。持有者經蟲神授與悲愴之刃後，可成為蜂王統御全族。啟動蜂璽時，雅納轉為血紅色的日全蝕，紅色能量可吸乾狂戰士的精髓並操控其設施。
- 歷史：埃蘭迪紀年 2433 年經蜂璽開啟的傳送門入侵，摧毀菲亞海頓帝都；2445 年被鎮神劍與蜂璽封印。經過見 [../world-background.md](../world-background.md)。
- 蜂王：盧因化為蜂王，原因是拒絕獻祭艾依姆索，詛咒因此應驗（傾向，未定案）。第二任蜂王艾依姆索立誓「唯獨在吾等點頭，行動才可發起」，自囚於睡夢之城深處的玻璃棺中長眠，只要他不點頭，狂戰族就無法回歸。誓約被打破的後果尚未設定。
- 封印地有兩種說法（待定）：寂域；睡夢之城。寂域、睡夢之城與諸皇廟的關係見 [../open-questions.md](../open-questions.md)。
- 睡夢之城怎麼進入尚未決定（待定）。
- 設計參考：異形風格的科幻設定與暗黑奇幻的深淵生物。

## 盲魂（The Blind）

- 棲息於寂域亞空間的黑暗生物，寂域是被黑暗風暴覆蓋的亞空間。
- 外觀有兩種說法（待定）：
  - 由纏繞的枝蔓與扭曲的骨肉構成，頭部如人骨，有五個不規則的眼窩卻無視覺，腹部是唯一的要害。
  - 無形的幽魂聚合體，會啃噬精神與記憶，火焰精靈稱之為「看不見的哭泣者」。
- 能力：以黑暗風暴為掩護，高度隱匿；對聲音與振動極為敏感；以枝蔓捆綁敵人並吸取能量；以黑暗能量為食。
- 外界所知甚少，多存在於傳說與恐怖故事中。
- 唯一的事蹟是戈洛禍古斯圍城事件中經地下河道與裂隙入侵納黑索，事件發生的時代待定，可能在神權之戰之後。入侵的原因尚未設定，與睡夢之城碎裂是否有關待定。
- 尚未設定：與狂戰族、異械的關係。
- 設計參考：異形恐怖與暗黑奇幻中的亞空間生物。
