# 遠古遺族

永庭族、龍族、門戍族與神罩。永庭族創造了萬物與智慧種族，其餘三者都與永庭族直接相關。

## 永庭族的繼承種族

- 現有說法：永庭族創造塔尼亞（人類）、埃爾蘭（精靈）、門戍（矮人概念）三個繼承種族。後來認為門戍與矮人是不同的概念，草擬了矮人奧修斯。
- 這個問題尚未決定（待定）：
  - 方案甲：保留三個繼承種族，第三個改為奧修斯，門戍族改為永庭族的使者種族。
  - 方案乙：保留三個繼承種族，第三個仍是門戍族，不另設矮人。
  - 方案丙：不保留三個繼承種族，改設計更多智慧種族。
- 保留三個繼承種族可以讓故事不偏離原始設定，但設計常見；不保留可以增加豐富性，但世界資源分配與歷史重寫的範圍過大。

### 奧修斯（Othes，矮人）（草案）

- 為了將「門戍」與「矮人」拆成兩個概念而草擬的種族，是否採用取決於上述方案。
- 若採用，奧修斯取代門戍族成為永庭族創造的繼承種族之一。
- 門戍族與矮人是最後一波西遷的族群。這與門戍族帶領伊阿薩族西遷的寫法不一致，待定。
- 種族外觀：身形矮壯，蓄鬚編辮，衣飾以幾何紋樣的織毯與金屬鱗甲為主。（草案）
- 文化：重視誓約與世系，以石刻與口傳史詩記錄家族歷史。（草案）
- 設計參考：矮人概念為基礎，結合波斯與斯堪地那維亞。

## 永庭族（The Arch）

- 由第一個生命冕族轉化而成的先行者。冕族從創世者撒冽亞的樂章中誕生，外形如帶妖精翅膀的火焰電漿；聖繭破裂後失去光之形態，成為有物質形體的永庭族。
- 使命：承接撒冽亞未完成的樂章，研究生命的本質。最終目的是找到能傳承使命的種族，由其取代自己。
- 事蹟：建造天輪；創造龍族與萬物；與異械作戰；建造鎮神劍；以亞巴頓協議毀滅聖繭、與異械同歸於盡；在新世界創造精靈、人類等繼承種族；為神權之戰立下規則並賜下萬軍神歌；之後退隱。
  - 規則與萬軍神歌見 [../divine-war.md](../divine-war.md)。
- 退隱的時間有三種說法：創造三族後就消失；異械戰爭結束時進入隱藏；神權之戰結束後才退隱。傾向最後一種（傾向，未定案），與 [../divine-war.md](../divine-war.md) 一致。
- 組織：聖謳環負責創造生命。
- 遺產：鎮神劍、神罩、基石聖樹、沙盒、水仙花聖座、世界之錨、萬軍神歌等。
- 別稱：龍族稱其為「燧」，意為種火種者。
- 在精靈眼中的形象見 [elves.md](elves.md)。
- 永庭族不回應信仰，見 [../gods.md](../gods.md)。
- 尚未設定：外貌；社會結構；退隱後的去向；與門戍族的血緣關係。

## 龍族與泰烽神域（Typhoon Sharine）

- 真龍族在聖繭時期由永庭族於某個天輪創造（傾向，未定案；另有說法是聖繭毀滅後才與精靈、人類一起被創造）。
- 唯一跨越滅絕時期存活的智慧種族，隱居於世界最外環的龍之鄉，作為旁觀者與關鍵時刻的指引者。
- 壽命與力量超越時間；謙遜低調。掌握部分宇宙權能（草案），見 [../power-system.md](../power-system.md)。
- 泰烽神域位於外環，毗鄰渾沌之海，四周有暴風與天然屏障。境內有赤紅的火山山脈、寧靜的綠洲、被視為聖繭殘餘力量的聖泉，以及記錄宇宙法則的古老石碑。
- 文化以「言語真理」為核心，以古龍語傳承智慧與歷史。內部平等、智慧共享，沒有固定的統治階層。
- 幾乎不與任何勢力衝突，只在世界秩序或生態平衡崩塌時干預。多數人類與精靈從未親眼見過龍。
- 龍族作為族群不插手世事，也不回應信仰；個別的龍可能回應。迷霧紀元時曾有一群龍暫居火山島，指引海洋精靈前往烽火堡壘。
- 龍神信仰見 [../gods.md](../gods.md)，規劃待定。
- 尚未設定：外貌與數量；個體角色；亞龍的設定（是否採用待定）。
- 設計參考：東方龍文化，結合西方奇幻中的智慧型古龍。

## 門戍族（Gatekeeper）

- 體型矮小，身體由高科技裝甲包覆，外殼常散發霓虹光芒。
- 起源有多種說法（待定）：永庭族的嫡系後裔；永庭族的退化後裔；永庭族意識的傳承體；永庭族的使者種族。
- 使命：保護發展中的雅拉世界；守護渺脈傳送門的能量；守護鎮神劍；建造傳送門吸收紊亂的渺脈潮汐，防止大陸漂移。渺脈的部分見 [../power-system.md](../power-system.md)，以該文件為準。
- 能力：極高的工匠技藝，能修復古老遺物；攻防一體的自適應裝甲；掌握永庭族古老科技；能與神罩互動並維護，但無法控制或製造神罩；擁有驅逐艦。
- 事蹟：帶領伊阿薩族西遷，教導其感知渺脈，共建白港；守護基石聖樹；狂戰族入侵時最先迎擊，護送難民，引介精靈與人類結盟，重建通往鎮神劍的傳送門。
- 下落有兩種說法（待定）：對抗狂戰族耗盡氣數後淡出歷史，只留下工匠作品；或仍持續守護聖遺物並維持渺脈循環。
- 與永庭族的關係，以及只有門戍族有永庭信仰，見 [../world-background.md](../world-background.md)。
- 在精靈眼中受禮貌性的尊敬，不被崇拜。想了解永庭族遺跡者需與他們合作或取得許可。
- 尚未設定：裝甲之下的樣貌；社會結構與個體角色；與人類首次接觸的經過；與矮人奧修斯的關係。
- 設計參考：科幻與神話機械風格的融合。

## 神罩（The Tent，聖遺物）

- 永庭族創造的自動守衛，長期無意識地保護遺跡與聖物。本質接近無人機或自動化防禦裝置，可與人互動但無法被直接命令，不是崇拜對象。
- 能力：判斷入侵者意圖並警告、隔離或攻擊；模擬永庭族的建築、文化與自然環境；有限的時間回溯，可暫時重現過往的場景。
- 亞種：鋒芒（The Sharpe）為攻擊型，部署於遺跡核心；盾（The Shield）為防禦型，用於保護聖物或穩定渺脈。最強的個體稱為代理人。
- 所在：睡夢之城、護盾疆域與各處永庭族遺跡。護盾疆域位於世界中心（傾向，未定案）。
- 與門戍族：門戍族能與神罩溝通並維護，無法控制或製造新的神罩。護盾疆域的防衛原由門戍族負責，後由神罩全面接管。
- 護盾疆域的建造者有兩說（待定）：由永庭族的建築模塊包圍；或由門戍族與神罩族合作建造。
- 事蹟：蟲神現身時如蝗群般聚集攻擊，只能短暫拖延。
- 尚未設定：時間回溯的限制；與門戍族的分工；是否應由「種族」改列為「遺物」。
- 設計參考：科幻結構物與神話中的聖物概念，自動化防禦系統與奇幻魔法屏障。
