# 還沒決定的項目

## 留白

刻意先不決定。寫作與設計時不要自行補上。

- 地位等同永庭族的大神：來歷、數量，以及和龍族的關係。
- 重疊神位的上下級，例如太陽神與火神。
- 偽神的細分。
- 渺脈在後世的規劃（能量結晶、貨幣）。

## 待定

需要決定，但還沒有討論出結果。

- 綜合分數中，源質與信仰之力如何換算。
- 自然神位怎麼分類。
- 龍神信仰如何規劃。
- 專屬神器的具體規則，以及它是否代表神的偉力。
- 英靈兩種回到現世的方式，各自的條件與轉換率。
- 奇觀收集殘響的速度，以及建造的條件。
- 神域一類的場地設計。
- 各種族在神權之戰中的立場與細節。

## 尚未整合的雅拉設定

雅拉設定集裡還有一些和神權之戰相關、但尚未定案的題目。這些不影響目前的遊戲設計，定案後再補進來。

- 神權之戰在編年史上的確切位置，以及故事重寫版本的取捨。
- 寂域、睡夢之城、諸皇廟三者的關係。
- 門戍族的身分與下落。
- 權能三分法的細項。
