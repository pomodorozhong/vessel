# 神權之戰

## 一句話

聖歌耗盡後，用過的聖歌留下的殘響散落各地、混在一起，擾亂世界的平衡。永庭族定下規則，讓各族用一場戰爭競賽把殘響收進容器、梳理成源質。這場分類與收納就是神權之戰。

## 用珠子來想

1. 原本世界充滿聖歌。聖歌可以轉換成任何一種珠子，也會自己轉換成別的珠子。
2. 戰爭過後聖歌減少，各種顏色的珠子混在一起，擾亂了平衡。
3. 所以找了能使用這些珠子的人（神）來處理。火的神專門撿火的珠子，水的撿水的。他們本身也算一種力量源。
4. 為了讓他們積極，用戰爭的方式並設定規則，讓他們更快去收容散落各地的珠子：找無主的，也掠奪分散各地、有主但弱小的持有者。

## 性質

- 不是單一地區的衝突，也不是純粹的全球敵對戰爭，而是各族在規則下進行的戰爭競賽，其中包含無數次小型的利益爭奪。
- 是永庭族有意為之。永庭族早有計畫，但因為聖歌耗竭、鎮神劍被重啟，時機被迫提前。起因見下一節。
- 永庭族只定規則，不事先決定有哪些神位。
- 對世界來說，神在主世界的戰鬥等於把梳理過的力量重新輸入世界。

## 起因與時間位置

- 根因是聖歌耗盡。只要聖歌耗盡，就必須用容器吸收、轉化殘響，神權之戰就會發生。
- 聖歌越來越少，一直是那個時代研究的課題。
- 神權之戰與異械戰爭沒有直接的因果關係。異械戰爭在聖繭時期，早得多。
- 狂戰族之戰和神權之戰是兩場不同的戰爭，時間上相隔很遠。狂戰族之戰只是加速了聖歌的耗盡：為了封印狂戰族而重啟鎮神劍，加上帝國長期大量使用聖歌，聖歌資源在戰後耗竭。
- 兩場戰爭之間的經過是：聖歌資源耗竭，氣候異常，萬族大遷徙開始，永庭族消失已久、神權信仰初現，然後神權之戰開打。
- 永庭族定下規則，這就是永庭族對戰爭的干預，目的是保護雅拉。聖歌在神權之戰期間從雅拉完全消失。

## 神就是容器

- 靠吸收殘響成神的神，來源是人類。另一條路是信仰聚集而成的神，兩條路見 [gods.md](gods.md)。
- 人類吸收能量成為超人類，這個行為本身就具備過濾與容器的功能。
- 吸收得越來越多、開始影響世界之後，只能開闢亞空間（神域）存放能量。到這個階段才稱為神，但本質上仍然是容器。

## 萬軍神歌

- **開戰時**是出現在天空的石板，公告戰爭的戒律與規則，戰爭由此開始。
  - 很大，大約佔半個天空。
  - 不是人人都看得見，只有吸收過力量的人看得見。
  - 碰不到，也到不了它的正下方。想看清它時會實體化，不注意時又變得半透明。
- **戰爭結束後**與大陸一起碎裂成七塊，成為七大陸各一塊的石碑，保存最後的聖歌，地位相當於十誡。
- 戰後的石碑是成神的加冕場所，也可以是國王的加冕場所、中立區域或特殊的祭壇。

## 參與者

- 參戰的種族沿用雅拉設定集既有的種族。
- 神與神眷者都會吸收殘響。
- **偏好和平的族群**同樣參戰，但通常是被動應戰或復仇，不以掠奪為目的。他們主要靠信仰之力累積分數，也可以建造奇觀來收攏殘響。
- **地位等同永庭族的大神**依規則可以下場，但對他們沒有意義，所以不打。
- **永庭族與龍族**不參賽。違規的處置由永庭族或龍族執行，沒有信使，從參戰者的視角看不到執行者。

## 過程

- 世界遼闊，所以是各個地區各自打。
- 殘響分區域與全域兩層。一個區域的殘響耗盡，那個區域的戰爭就結束，其他區域還在繼續；全域的殘響耗盡，整場神權之戰結束。
- 出兵、轉化、奇觀的吸收都會讓殘響下降，所以打得越兇、收得越快，戰爭結束得越早。
- 上戰場的大多是受到祝福的普通人，為信仰而戰。
- 弱小的持有者會被掠奪。有幾萬身家的人打不過大戶，但會彼此爭奪，想往上爬。
- 真正強大的神需要普通信眾與高階信眾，所以會形成神殿團體。

## 結束與結算

- 世界上的殘響降到近乎零時結算。
- 結算是綜合比拼，分數由三項組成：
  - 自己吸收的殘響所轉化的源質。
  - 經由自己轉化出來的源質。
  - 信仰之力，例如庇護了多少民眾。
- 所以獲勝的方式不只有武力。把所有對手都打倒也是一種贏法，但不是唯一的一種。
- 萬軍神歌計算分數，永庭族主持加冕。
- 同一個神位由綜合分數高的加冕，不另外對決。落敗者成為從屬神，或轉為信仰神。
- 加冕之後神進入亞空間，永庭族自世間退隱，七環大陸成形。

## 戰後

- 分類在神權之戰結束時完成。收攏後的力量在亞空間與主世界都有，亞空間是源頭。
- 戰後還可以出現新的神，但力量已經分得差不多，新的神基本上都是信仰神。
- 戰後的細節不在這份設定的範圍內。
