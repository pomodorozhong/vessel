# 時間軸

從創世到神權之戰結束、永庭族退隱、七環大陸成形為止的單一時間軸。之後的建國時期、近代與現代不在這份文件的範圍內。

## 讀法

- **已知**：原事件表標為不能更動的事件。
- **預期**：已有規劃、細節待補的事件。
- **不確定**：設定模糊、需要重置或仍在構思的事件。只出現在簡表或精靈史敘事裡、沒有列入事件表的項目也標為不確定，備註會說明。
- 事件表是故事重置前的內容，標為已知的項目照樣標已知，之後要逐一重新確認。作者的初步傾向是把這些定案全部降為草案（傾向，未定案）。
- 同一件事有不同說法時，有傾向的寫成傾向，沒有傾向的並列並標（待定）。

## 兩套時代劃分

| 劃分 | 順序 |
| --- | --- |
| 紀元劃分 | 起源（創世初期）、聖繭時期、滅絕時期、新世界 |
| 時代劃分 | 創世紀、遠古、古代、中世紀、近代、現代 |

- 這份文件涵蓋到遠古時期末期。古代以後的欄位不收。
- 大時代底下再切成九個階段，各階段的範圍與設定見 [eras.md](eras.md)。
- 滅絕時期的範圍有兩種算法（待定）：從異械誕生算起；一直延續到神權之戰結束。FigJam 的時間線畫成從聖繭毀滅前後開始，延續到神權之戰結束。
- 異械戰爭只有聖繭時期這一次。後來的狂戰族之戰與異械有關，但入侵的不是異械，見 [cosmology.md](cosmology.md)。

## 尚待決定的地方

- **永庭族退隱的時間**：目前寫成神權之戰結束之後（傾向，未定案）。另外兩說是創造三族後就消失，以及異械戰爭結束時進入隱藏。
- **神權之戰的時間點與故事重寫版本**（2026-11-24 決定方向）：
  - 決定：異械戰爭在前，神權之戰在後，維持現有寫法。神權之戰的根因是聖歌耗盡，與異械戰爭沒有直接因果，見 [divine-war.md](divine-war.md)。
  - 版本二只採用兩點：神的來源是人，以及衛哨被送入深淵。衛哨不是異械的來源，而是後來被同化的一批，見 [cosmology.md](cosmology.md)。版本二「異械戰爭晚於神權之戰」不採用。
  - 以下保留各版本的原貌，供對照。
  - 現有寫法：放在菲亞海頓滅亡、聖歌耗盡之後的遠古末期。
  - 版本一：只處理西遷與起源。三族誕生於原始大陸且和諧無部落；聖歌消失、寒冰期降臨；門戍族帶領部分精靈與人類離開；伊努提芮瑟族脫離；菲亞海頓聯合帝國成立；人類與矮人跟進西遷。
  - 版本二：大幅修改。三族誕生於始源大陸；部分人因能使用聖歌而成為信仰神；永庭族的衛哨私自收回聖歌；信仰神相爭；衛哨被送入深淵銷毀卻成為異械；異械戰爭中信仰神敗亡，永庭族帶著生命火種前往雅拉。
  - 差異：版本一的異械戰爭早於三族誕生，版本二的異械戰爭晚於神權之戰，且異械的來源改為衛哨。
- **繼承種族是否保留三族**（待定）：甲，保留三族，第三家改為奧修斯，門戍族改為永庭族的使者種族；乙，保留三族，第三家仍是門戍族；丙，不保留三族，改設計更多智慧種族。
- 時間軸的空白：龍族與門戍族在時間軸上幾乎沒有事件。
- 狂戰族之戰的年代：故事給出距今一萬兩千多年，其後迷霧紀元約三千多年。
- 精靈壽命長，精靈的歷史紀錄與其他種族的紀錄會有割裂感，同一件事看起來像不同時代的產物。
