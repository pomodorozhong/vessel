# 名詞表

以這張表的寫法為準。

## 力量

| 名詞 | 意思 | 其他寫法 |
| --- | --- | --- |
| 聖歌 | 創世能量，世界原本的力量，已在狂戰族之戰中耗盡 | |
| 殘響 | 聖歌被使用後的轉換物與殘留，要梳理才能再用 | 珠子（討論時的比喻） |
| 源質 | 梳理過的殘響，神能直接使用的神力 | 原質、源能、源力 |
| 容器 | 收攏殘響的個體或位置，包含神位、神、神眷者 | vessel |
| 信仰之力 | 來自人群與信仰的力量 | 願力、信仰念力 |
| 渺脈 | 聖歌的下級，後世的能量；這個時代不賦予功能 | The Veil |
| 權能 | 神表現出來的能力 | 權柄 |
| 洞天福地 | 殘響自然聚集的地點 | |

## 神

| 名詞 | 意思 |
| --- | --- |
| 神位 | 分類完成後浮現的位置。自然神的神位各只有一個 |
| 神眷者 | 神在人間的代表，也是容器。遊戲中玩家的身分 |
| 自然神 | 力量來自殘響、對應自然神位的神 |
| 信仰神 | 力量來自信仰之力、需要載體的神 |
| 載體 | 信仰神依附的實體或物品 |
| 舊神 | 神權之戰時期的神，名字固定不變 |
| 新神 | 戰後出現的神，名字可以更換 |
| 加冕 | 戰爭結束時被認可並送入亞空間的過程；也指這個地位 |
| 從屬神 | 落敗後依附在加冕者之下的神 |
| 無主神 | 失去信徒的信仰神 |
| 偽神 | 不被承認的神，細分未定 |
| 專屬神器 | 神交給神眷者的力量投射，也可以是信仰神的載體 |

## 戰爭

| 名詞 | 意思 |
| --- | --- |
| 神權之戰 | 各族在永庭族的規則下收攏殘響的戰爭競賽 |
| 萬軍神歌 | 開戰時是天空的石板，戰後碎成七大陸各一塊的石碑 |
| 祭壇 | 各方的據點，等同堡壘與旗 |
| 奇觀 | 神與信徒合建、用來收集殘響的大型建築 |
| 神殿團體 | 神與普通信眾、高階信眾聚成的團體 |

## 世界

| 名詞 | 意思 |
| --- | --- |
| 雅拉 | 故事所在的世界 |
| 亞空間 | 與雅拉相鄰的空間層，神的國度所在 |
| 永庭族 | 創造萬物與智慧種族的先行者，神權之戰的規則制定者 |
| 龍族 | 永庭族創造的古老種族，隱居泰烽神域 |
| 門戍族 | 永庭族的遺民 |
| 狂戰族 | 世界之敵 |
| 菲亞海頓 | 聖歌時代的帝國，亡於狂戰族之戰 |
| 鎮神劍 | 永庭族的神器，重啟它封印狂戰族時耗盡了聖歌 |
| 泣霜露冬 | 聖歌耗盡後的全球寒冰期 |
| 七環大陸 | 神權之戰結束時成形的七塊大陸 |
