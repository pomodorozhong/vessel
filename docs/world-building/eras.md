# 時代標籤與各時代設定

雅拉的時代劃分，以及每個時代「有什麼、沒有什麼」。寫設定、寫故事、做遊戲時，先查這一頁，確認要寫的東西在那個時代存在。

這一頁以 FigJam 的時間線「雅拉詳細歷史」為基礎。事件的先後以時間線為準，逐項事件見 [timeline.md](timeline.md)。

三個欄位與九個階段的切法、名稱已於 2026-11-24 採用。各階段表格裡標（待定）的格子還沒決定。

## 三個標籤欄位

每個條目（人物、地點、事件、種族、器物）用三個欄位標示時代。三個欄位各自獨立，不混用。

| 欄位 | 用途 | 可用的值 |
| --- | --- | --- |
| 大時代 | 最粗的劃分，對應時間線最下面一列「時代分類」 | 創世紀、遠古、古代、中世紀、近代、現代 |
| 階段 | 大時代底下，照核心事件切出來的段落 | 見下一節的九個階段 |
| 精靈分期 | 精靈自己的紀年，只在精靈相關的條目使用 | 航離期、菲亞海頓期、流離期、今世期 |

- 時間線最上面一列「紀元名稱」（起源、聖繭時期、滅絕時期、新世界）不另設欄位，可以從階段推得，對應關係列在下一節的表裡。
- 條目橫跨多個階段時，填起點與終點，例如「聖歌帝國～狂戰族之戰」。
- 時間不明的條目填「未定」，不要猜。

## 九個階段

| 順序 | 階段 | 大時代 | 紀元名稱 | 精靈分期 | 時間線上的範圍 |
| --- | --- | --- | --- | --- | --- |
| 1 | 起源 | 創世紀 | 起源（創世初期） | | 撒冽亞創造聖繭，冕族誕生，聖繭破裂與修復 |
| 2 | 聖繭盛期 | 創世紀 | 聖繭時期 | | 永庭族誕生，萬物初生，龍族誕生，史前御三家演化，異械誕生 |
| 3 | 異械戰爭 | 創世紀 | 聖繭時期 | | 異械舉止異常，鎮神劍建造與落成，異械戰爭，亞巴頓協議，聖繭毀滅 |
| 4 | 火種復甦 | 遠古 | 滅絕時期 | 航離期 | 生命火種與初始御三家，歷史文化復甦，永庭族淡出群眾視野 |
| 5 | 聖歌帝國 | 遠古 | 滅絕時期 | 菲亞海頓期 | 菲亞海頓帝國成立，聖歌時代開啟，大量應用聖歌並預測資源耗竭，研究鎮神劍 |
| 6 | 狂戰族之戰 | 遠古 | 滅絕時期 | 菲亞海頓期 | 意外解放狂戰族，入侵，菲亞海頓淪陷，精靈與人族協力，帝國沉沒，狂戰族被封印 |
| 7 | 耗竭與大遷徙 | 遠古 | 滅絕時期 | 流離期 | 聖歌資源耗竭，氣候異常，精靈遷徙，萬族大遷徙開始，神權信仰初現 |
| 8 | 神權之戰 | 遠古 | 滅絕時期 | 流離期 | 神權之戰開打，永庭族干預，聖歌從雅拉消失，戰爭結束，神明離開雅拉，永庭族正式消失 |
| 9 | 新世界 | 古代以後 | 新世界 | 流離期末～今世期 | 古代、中世紀、近代、現代。不在 vessel 的範圍內 |

- vessel 這款遊戲發生在第 8 個階段。
- 第 6 與第 8 個階段是兩場不同的戰爭，中間隔著第 7 個階段，不要寫在一起。
- 創世紀在異械戰爭結束、世界毀滅時終結，遠古從生命火種開始。
- 流離期又稱迷霧紀元，以貝亞蘭瑰稜茨建國為結束，所以會跨進新世界的開頭。迷霧紀元與神權之戰在時間上如何對應，見 [open-questions.md](open-questions.md)。
- 萬族大遷徙在神權之戰期間結束，那時大部分族群的地盤已定。
- 第 7 個階段的氣候異常就是寒冰期，事件名稱是「泣霜露冬」。
- 精靈各氏族遷徙、找到新土地的經過，從第 7 個階段一路延續到第 8 個階段開打的過程中。這類條目的階段填「耗竭與大遷徙～神權之戰」。

## 各階段有什麼、沒有什麼

### 力量與神

| 階段 | 聖歌 | 神 | 永庭族 |
| --- | --- | --- | --- |
| 1 起源 | 世界充滿聖歌 | 沒有 | 還沒出現，只有冕族 |
| 2 聖繭盛期 | 世界充滿聖歌 | 沒有 | 由冕族演化而來，創造萬物與智慧生物，建造天輪 |
| 3 異械戰爭 | 世界充滿聖歌 | 沒有 | 與異械作戰，建造鎮神劍，最後啟動亞巴頓協議 |
| 4 火種復甦 | 有 | 沒有 | 創造繼承種族，之後淡出群眾視野 |
| 5 聖歌帝國 | 聖歌時代，被大量使用，已預測會耗竭 | 沒有 | 不在群眾視野中，只留下聖遺物 |
| 6 狂戰族之戰 | 重啟鎮神劍時大量消耗 | 沒有 | 不在群眾視野中 |
| 7 耗竭與大遷徙 | 資源耗竭，只剩殘響散落各地 | 神權信仰初現。人吸收能量成為超人類，還不算神 | 消失已久 |
| 8 神權之戰 | 在戰爭期間從雅拉完全消失 | 神就是容器，在規則下收攏殘響；戰後加冕，進入亞空間 | 定下規則干預戰爭，戰後正式消失 |
| 9 新世界 | 沒有。世界改以渺脈運作 | 神在亞空間，只能賦予力量 | 沒有 |

### 敵人與鎮神劍

| 階段 | 世界之敵 | 鎮神劍 |
| --- | --- | --- |
| 1 起源 | 沒有 | 沒有 |
| 2 聖繭盛期 | 異械已誕生，還沒有敵對 | 沒有 |
| 3 異械戰爭 | 異械 | 建造並落成。鎮壓通往封印異械那個空間的通道 |
| 4 火種復甦 | 沒有 | 存在，由門戍族守護 |
| 5 聖歌帝國 | 沒有 | 帝國把它當成解決聖歌耗竭的線索來研究 |
| 6 狂戰族之戰 | 狂戰族。與異械有關，但不是異械 | 鎮壓減弱、通道露出；之後被重啟，用來封印狂戰族 |
| 7 耗竭與大遷徙 | 沒有設定（待定） | 沒有設定（待定） |
| 8 神權之戰 | 沒有設定（待定） | 沒有設定（待定） |
| 9 新世界 | 不在範圍內 | 接上渺脈穩固封印，多餘的能量用來做傳送門 |

### 舞台與種族

| 階段 | 主要舞台 | 智慧種族 |
| --- | --- | --- |
| 1 起源 | 渾沌之海、聖繭 | 撒冽亞、冕族 |
| 2 聖繭盛期 | 聖繭內的天輪 | 永庭族、龍族、史前御三家 |
| 3 異械戰爭 | 聖繭內的天輪 | 永庭族、龍族、史前御三家 |
| 4 火種復甦 | 努亞迪雅（後來的雅拉） | 龍族、初始御三家。御三家是否保留三族仍待定 |
| 5 聖歌帝國 | 菲亞海頓 | 精靈為主的帝國，人類與其他族群在帝國內外 |
| 6 狂戰族之戰 | 菲亞海頓、卡恩薩 | 精靈與人類結盟，門戍族迎擊 |
| 7 耗竭與大遷徙 | 遷徙途中的各地，例如德蘭德洛特山脈 | 各族分散遷徙 |
| 8 神權之戰 | 各地區各自開戰 | 參戰種族見 [divine-war.md](divine-war.md)，各族立場仍待定 |
| 9 新世界 | 七環大陸 | 不在範圍內 |

- 七環大陸成形的時間點，時間線上標為待討論。目前其他文件寫成神權之戰結束時成形。

## 後世怎麼看這些階段

時間線下半部的「歷史紀錄」與「世俗理解」兩列。寫後世的故事時，角色知道的是這一欄，而不是實情。

| 階段 | 後世的理解 |
| --- | --- |
| 1 起源 | 沒有歷史 |
| 2 聖繭盛期 | 創世紀，類似伊甸園的想像 |
| 3 異械戰爭 | 異械入侵，滅世。紀錄已被摧毀 |
| 4 火種復甦 | 舊神宗教的生命起源紀錄 |
| 5 聖歌帝國 | 傳說中的神國、遠古高科技帝國，烏托邦或伊甸園的原型 |
| 6 狂戰族之戰 | 考古上是導致帝國滅亡的滅世等級戰爭，被誤認成異械入侵的歷史證明 |
| 7 耗竭與大遷徙 | 沒有對應的紀錄（待定） |
| 8 神權之戰 | 舊神明的戰爭、遠古戰爭；神話時代，神明真實存在的依據；現代魔法的起源；舊神明與新神明的分歧點 |

## 還沒決定的

- 第 7、8 個階段的世界之敵與鎮神劍狀態。
- 七環大陸成形的時間點。
- 新世界之後（古代、中世紀、近代、現代）還沒有安排。戈洛禍古斯圍城這類事件先歸在新世界，大時代填未定。
