# 設定對應到遊戲

這一頁只記錄設定上已經決定、會影響遊戲設計的部分。玩法的規格不在這裡。

## 玩家

- 玩家扮演**神眷者**：神在人間的代表，本身也是容器。
- 專案名稱 vessel 指的就是容器。

## 戰場

- 地圖上有兩軍或三軍在交戰。
- 玩家可以下場戰鬥、成長，也可以打掉對方的祭壇。
- 場地可以有神域一類的設計（草案）。

## 祭壇

- 祭壇就是各方的堡壘與旗。
- 打掉對方的祭壇是戰鬥的勝利條件。

## 奇觀

- 由神與信徒合建，使用永庭族的技術。
- 只負責收集殘響。
- 神眷者要到奇觀把殘響轉化成源質，用來強化自身。轉化後的源質不會散開。
- 奇觀建成後會持續吸收所在區域的殘響，區域的殘響因此加速下降。
- 奇觀可以被摧毀，所以會成為敵人優先攻擊的目標。被毀時，尚未轉化的殘響會散回區域；已經被神眷者轉化的部分不會回去。
- 守住奇觀到區域的殘響耗盡，奇觀裡剩下的殘響會歸守住的一方。

## 資源

| 資源 | 在遊戲裡的意義 |
| --- | --- |
| 殘響 | 散落在地區裡、可以收集與掠奪的原料 |
| 源質 | 殘響在奇觀轉化後的成果，用來強化神眷者 |
| 信仰之力 | 來自信眾，和源質一起計入結算 |

渺脈在這個時代不是資源。

## 神能給玩家的東西

- **專屬神器**：神交給神眷者的力量投射。
- **英靈**：陣亡信徒可以把力量投射回現世，或被召喚短暫現身，依神而定。

## 一場戰爭怎麼算贏

- 單場戰鬥：打掉對方的祭壇。
- 一個區域：區域的殘響耗盡，該區域的戰爭結束。
- 整場神權之戰：全域的殘響耗盡時，以源質與信仰之力的綜合分數結算，組成見 [divine-war.md](divine-war.md)。
- 設定提供的是多種獲勝方式，不只是把對手打倒。

玩法還沒有開始設計。討論中提過的玩法想法另外記在 [gameplay-notes.md](gameplay-notes.md)，都還不是定案。
