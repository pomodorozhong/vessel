# 精靈

精靈（埃爾蘭）的本質，以及聖歌時代到遷徙期間的樣貌。建國後的各個精靈國度不在範圍內。

## 名稱

- 種族名：埃爾蘭。
- 航離期與菲亞海頓期稱伊阿薩（Eaz），迷霧紀元起稱精靈（Elves）。

## 起源

- 由永庭族的聖謳環創造，稱為「壹型接觸」，誕生於傳說中的艾姆茵露。
- 是最早誕生的高等智慧種族，早於人類。
- 誕生地另有庫維茵凡一說，兩者的關係待精靈語翻譯完成後再決定（待定）。
- 永庭族創造了哪幾個繼承種族，見 [ancient-races.md](ancient-races.md)。

## 本質

- 智慧型魔法生物，體內有魔核。魔核是魔法生物體內運作渺脈的核心功能，名稱為暫名，是功能分類而非器官。
- 外觀與天賦會隨居住地的渺脈特性改變，小至健康變化，大至永久性的外觀演化或能力。
- 個體壽命長於大部分種族。
- 早年的精靈容易發生渺脈紊亂，因此各氏族發展出專屬的成年儀式（洗禮）來穩定魔核。洗禮的通則見 [README.md](README.md)。
- 擁有魔核的伊阿薩族難以抵抗狂戰族的污染，見 [enemies.md](enemies.md)。
- 精靈與其他魔核生物、元素生物優先結伴西遷。
- 渺脈在神權之戰時期不賦予功能，與上述寫法不一致，以 [../power-system.md](../power-system.md) 為準，魔核如何改寫待定。

## 價值觀

- 順天而行，勢頭順時積極而為，不順時退守不爭。
- 不排斥科技，發展上看重「溝通」與「分配」。
- 認為萬物有靈性，但不加以擬人化。
- 精靈不奴役族人。

### 與人類的思維差異

| | 精靈 | 人類 |
| --- | --- | --- |
| 對萬物的看法 | 萬物有靈性，但不擬人化 | 自然是資源的收取與回饋 |
| 發展科技時看重 | 溝通、分配 | 原理、用途 |
| 處世 | 順勢而為 | 多樣性、機會性、不確定性 |
| 魔法 | 魔核運作渺脈 | 不會直接施法，見 [humans.md](humans.md) |

## 對永庭族與神的看法

- 在精靈眼中，永庭族近似神，但不是祖靈或唯一神。精靈對他們是感激與尊敬，不是信仰。部分精靈相信他們未曾真正離開，會在重大危機時歸來。
- 永庭族不回應信仰，有永庭信仰的只有門戍族。精靈的神基本上都是信仰神，見 [../gods.md](../gods.md)。

## 歷史分期簡述

前後的世界背景見 [../world-background.md](../world-background.md)，這裡只記精靈方面。

1. **聖歌時代**：世界充滿聖歌，資源豐沛。伊阿薩族尚未熟悉渺脈，透過基石聖樹被動獲得能量。伊阿薩族依聖歌創造文化特徵與儀式，其中一些造成永久性的改變，成為海洋精靈、錫繆精靈等氏族的基礎。
2. **西遷（航離期）**：門戍族帶領伊阿薩族西遷，教導他們感知渺脈，共建白港。少量人類隨行。
3. **菲亞海頓期**：帝國已預測到聖歌枯竭並著手研究，盧因的失誤即發生在研究過程中。人類在帝國中是不受重視的平民。
4. **狂戰族之戰**：精靈難民在卡恩薩與人類古氏族結盟，詳見 [humans.md](humans.md) 與 [enemies.md](enemies.md)。
5. **迷霧紀元**：菲亞海頓滅亡後，精靈不再建立統一帝國，氏族各自分化。這個時期在編年史上與神權之戰的先後關係尚未整理，見 [../open-questions.md](../open-questions.md)。

## 氏族的分化

各氏族在不同地域長期居住，受當地渺脈影響，形成不同的外貌與天賦。以下只記分化的起源，不寫建國以後。

| 氏族 | 外觀 | 天賦 |
| --- | --- | --- |
| 森林精靈 | 金髮、碧眼、尖耳，以鹿角與玉石為裝飾，常與鳥為伴 | 與森林與萬物溝通，天生能與鳥溝通，掌握花草樹木的渺脈 |
| 高原精靈 | 馬耳馬尾的獸人型，髮色與毛色多樣 | 與動物互通靈性，尤其是馬；身手矯健，箭術不遜森林精靈 |
| 海洋精靈 | 灰色或淺青色長捲髮，白膚，身上散發微弱光澤 | 感知水中生物與海洋的心跳，擅長琉璃魔法與占星 |
| 火焰精靈 | 黑灰色長髮，黃膚，偶有紅髮，尖耳，瞳孔黑而大 | 與岩石礦物通靈，親近火元素 |

### 森林精靈

- 埃盧溫率族人自白港出發，暫居多里希，與凱勒希伊米斯在千謐之境發現並命名貝亞蘭。
- 初期只能在夢遊者平原建立簡易聚落，後翻越希斯瑞凡山脈定居。

### 高原精靈

- 起源有兩種說法（待定）：
  - 森林精靈分裂後的族群，逐漸發展出適應高原生活的游牧文化。
  - 自白港與森林精靈同行後脫隊北上。遭狼群襲擊時獲帝王禽所救；受食人妖與鹽暴所迫而遷徙，攀越庫散科，抵達最西方的格蘭拉爾斯平原。「錫繆」意為鳥人。
- 所在的大陸待定。
- 馬耳馬尾的由來（渺脈或權柄的影響）尚未設定。
- 同族大將鄒科與蟲神「鄒」同字，是否改名待定。

### 海洋精靈

- 祖先是白港天琴族。自白港向西出海，決定不在陸地上與他族競爭。
- 在火山島初遇龍族，於烽火堡壘取得世界地圖，造出潛艦射水魚。
- 馴服濤驥並繪出第一張洋流圖，是第一個環遊雅拉的族群。
- 海洋精靈與火焰精靈疑似有遠古的戰爭，起因與經過都沒有寫出（待定）。

### 火焰精靈

- 祖先是泰彼瑞斯族，又名伊努提芮瑟族。伊阿薩族西遷時，他們被德蘭德洛特山群的火山吸引而留下。
- 菲亞海頓帝國中期，工匠西爾嘉特受極光吸引，順著海爾蕾火河來到熱點核心，發現永庭族的水仙花聖座。此地成為首都納黑索的前身。
- 德蘭德洛特山脈是世界上面積最大的山脈群。

餘燼精靈與塞納斯是建國以後才分化出來的族群，不在這份文件的範圍內。
