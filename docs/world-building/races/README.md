## 通用設定

- 各種族有洗禮（成年禮），透過某個方式獲取能量，可能是消耗物質或其他方式。
- 幼體容易死亡，洗禮也會產生負擔。
- 非人種的洗禮，能力有明確的方向。

## 狀態標記

沿用 [../README.md](../README.md) 的標記，另外加上：

- 沒有標記的內容是來源已經寫定的設定。
- 「草案」：方向已有、細節未定。來源中以【】標示為補寫的內容，保留並標為草案。
- 「待定」：來源有互相不一致的說法，或明列為待決。各說法並列，不擅自選邊。
- 「傾向，未定案」：已有初步傾向，但還不算定案。內容寫成該傾向。
- 「尚未設定」：來源明確表示還缺的部分。寫作與設計時不要自行補上。
- 條目的最後一行是設計參考，記錄這個條目參照的現實文化或其他作品。
