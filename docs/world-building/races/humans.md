# 人類（塔尼亞）

人類的起源、特性，以及神權之戰以前與精靈的關係。人類在後世建立的各國不在範圍內。

## 起源

- 種族名：塔尼亞。
- 永庭族創造的繼承種族之一，象徵創造力、潛力與開拓精神。
- 永庭族創造了哪幾個繼承種族，目前有三種方案（待定），見 [ancient-races.md](ancient-races.md)。

## 特性

- 不會使用魔法，喜好工具，講究邏輯與原理，有時又矛盾地迷信。
- 不易受狂戰族污染，擁有魔核的精靈則難以抵抗，見 [enemies.md](enemies.md)。
- 比精靈更具多樣性、機會性與不確定性。
- 對自然的態度是資源的收取與回饋，看重「原理」與「用途」。

### 魔法

- 人類沒有魔核，不能直接施法；貴族透過儀式、建築或盧伊南雅體系借用地脈的力量（傾向，未定案）。
- 人類使用渺脈需以外部裝置輔助（草案）。渺脈在神權之戰時期的地位見 [../power-system.md](../power-system.md)，以該文件為準。
- 尚未設定：人類如何使用魔法，或以科技取代魔法。

## 與精靈的關係

- 少量人類隨精靈西遷，在菲亞海頓帝國是不受重視的平民。
- 寒冷期爆發後有第二波人類西遷。
- 狂戰族之戰時，白王十二騎士與黑王七騎士的古氏族在卡恩薩接納精靈難民，並與精靈結盟。黑王的名字是否為亞伯（待定）。
- 精靈因意識到人類的崛起，不再建立統一帝國，避免與人類競爭。
- 精靈與人類的第一次接觸有三種說法（待定）：
  - 卡恩薩的相遇是伊阿薩族與人類的第一次接觸。
  - 菲亞海頓帝國內本來就有少數人類。
  - 狂戰族入侵前已有零星接觸。
